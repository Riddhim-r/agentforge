AgentForge

An AI agent that works in your browser.

Ask a question and AgentForge works out which tools it needs, runs them, reads the results and keeps going until it has an answer. You see every step.

  1. 1
    You ask

    Research, calculations, data analysis, a file to summarise.

  2. 2
    The model plans

    It chooses tools: web search, JavaScript, Python, file reading, charts.

  3. 3
    Tools run in this tab

    Code runs in sandboxed workers on your device, then the model answers from the results.

Bring your own key. AgentForge has no server, so it uses an AI model through your API key. The key is stored only in this browser and sent only to the provider you pick. Not sure where to start? OpenRouter gives one key for hundreds of models, including free ones.
